# apps/api

Gin + pgx + sqlc backend for CrowdTune.

## Stack

- Go 1.25
- gin-gonic/gin (HTTP)
- jackc/pgx/v5 + pgxpool (Postgres driver)
- sqlc (typed query generation)
- pressly/goose (migrations)
- caarlos0/env/v11 + joho/godotenv (config)
- log/slog (structured logging)

## Layout

```
apps/api/
├── cmd/api/main.go               wire-up only
├── internal/
│   ├── config/                   env parsing
│   ├── handlers/                 one file per resource
│   ├── db/
│   │   ├── queries/              .sql files for sqlc
│   │   └── sqlc/                 generated, do not hand-edit
│   ├── domain/                   pure types, no I/O
│   └── oapi/                     generated by oapi-codegen, do not hand-edit
├── openapi.yaml                  API contract
├── oapi-config.yaml              oapi-codegen config
├── sqlc.yaml                     sqlc config
└── Makefile                      common commands
```

## Setup

### Required tools

The Makefile assumes these are on `PATH`:

| Tool | Install on Windows |
|---|---|
| `goose` | `go install github.com/pressly/goose/v3/cmd/goose@latest` |
| `oapi-codegen` | `go install github.com/oapi-codegen/oapi-codegen/v2/cmd/oapi-codegen@latest` |
| `sqlc` | Download Windows binary from <https://github.com/sqlc-dev/sqlc/releases> (the `go install` route currently fails on Windows due to a CGO/pg_query toolchain mismatch with TDM-GCC) |
| `air` | `go install github.com/air-verse/air@latest` (optional, for live reload) |
| `golangci-lint` | <https://golangci-lint.run/welcome/install/> (do NOT use `go install` per upstream guidance) |

After install, ensure `%USERPROFILE%\go\bin` is on `PATH` so the Go-installed tools are reachable.

### Environment

Copy `../../.env.example` to `../../.env` and fill in the Neon `DATABASE_URL` and `DATABASE_URL_DIRECT`. Use
the **direct** URL (not the pooler) for migrations.

## Common workflows

```bash
make tidy              # go mod tidy
make build             # compile to bin/api
make run               # build and run
make dev               # air live reload (if installed)
make test              # go test -race
make vet               # go vet
make generate          # regenerate openapi + sqlc artifacts
make migrate-up        # goose up against DATABASE_URL_DIRECT
make migrate-status    # show pending migrations
```

## Adding an endpoint

Follow the workflow in `../../.claude/agents/gin-handler-author.md`:

1. Update `openapi.yaml` with the new operation.
2. Run `make openapi` to regenerate stubs.
3. Add the migration via `goose -dir ../../infra/migrations create <name> sql`.
4. Add the query in `internal/db/queries/<resource>.sql` with sqlc annotations.
5. Run `make sqlc-gen`.
6. Implement the handler in `internal/handlers/<resource>.go`.
7. Wire it in `cmd/api/main.go`.
8. Add a table-driven test.
9. `make vet build test`.
